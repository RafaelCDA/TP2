\hypertarget{index_intro_sec}{}\doxysection{\texorpdfstring{Introdução}{Introdução}}\label{index_intro_sec}
Sistema de backup e restauração desenvolvido para a disciplina de Técnicas de Programação 2, utilizando {\bfseries{TDD (Test-\/\+Driven Development)}} e seguindo uma {\bfseries{tabela de decisão}} fornecida.\hypertarget{index_features_sec}{}\doxysection{\texorpdfstring{Funcionalidades}{Funcionalidades}}\label{index_features_sec}

\begin{DoxyItemize}
\item Backup de arquivos listados em {\ttfamily Backup.\+parm}
\item Restauração de arquivos do backup
\item Verificação de integridade dos arquivos
\item Suporte a pendrive ou diretório local
\item Log de operações realizadas
\end{DoxyItemize}\hypertarget{index_tech_sec}{}\doxysection{\texorpdfstring{Tecnologias e Metodologias}{Tecnologias e Metodologias}}\label{index_tech_sec}

\begin{DoxyItemize}
\item {\bfseries{Linguagem}}\+: C++11
\item {\bfseries{Testes}}\+: Catch2 Framework
\item {\bfseries{Metodologia}}\+: TDD (Test-\/\+Driven Development)
\item {\bfseries{Cobertura}}\+: ≥80\% (verificado com gcov)
\item {\bfseries{Qualidade}}\+: cppcheck, cpplint, Valgrind
\end{DoxyItemize}\hypertarget{index_tdd_sec}{}\doxysection{\texorpdfstring{Desenvolvimento Orientado a Testes}{Desenvolvimento Orientado a Testes}}\label{index_tdd_sec}
O sistema foi desenvolvido seguindo rigorosamente a metodologia TDD\+:


\begin{DoxyEnumerate}
\item {\bfseries{Criar teste}} (baseado na tabela de decisão)
\item {\bfseries{Executar teste}} (deve falhar inicialmente)
\item {\bfseries{Implementar código mínimo}} para passar no teste
\item {\bfseries{Refatorar}} o código
\item {\bfseries{Commit}} do ciclo completo
\end{DoxyEnumerate}\hypertarget{index_structure_sec}{}\doxysection{\texorpdfstring{Estrutura do Projeto}{Estrutura do Projeto}}\label{index_structure_sec}
