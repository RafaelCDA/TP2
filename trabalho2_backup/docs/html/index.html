Introdução

Sistema de backup e restauração desenvolvido para a disciplina de Técnicas de Programação 2, utilizando TDD (Test-Driven Development) e seguindo uma tabela de decisão fornecida.

Funcionalidades

  • Backup de arquivos listados em Backup.parm
  • Restauração de arquivos do backup
  • Verificação de integridade dos arquivos
  • Suporte a pendrive ou diretório local
  • Log de operações realizadas

Tecnologias e Metodologias

  • Linguagem: C++11
  • Testes: Catch2 Framework
  • Metodologia: TDD (Test-Driven Development)
  • Cobertura: ≥80% (verificado com gcov)
  • Qualidade: cppcheck, cpplint, Valgrind

Desenvolvimento Orientado a Testes

O sistema foi desenvolvido seguindo rigorosamente a metodologia TDD:

  1. Criar teste (baseado na tabela de decisão)
  2. Executar teste (deve falhar inicialmente)
  3. Implementar código mínimo para passar no teste
  4. Refatorar o código
  5. Commit do ciclo completo

Como Usar

make coverage # Gerar relatório de cobertura
