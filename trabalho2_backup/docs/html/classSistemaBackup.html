Detailed Description

Classe principal do sistema de backup.

Responsável por gerenciar operações de backup e restauração baseadas na tabela de decisão fornecida no trabalho.

Desenvolvido seguindo TDD com Catch2 e com cobertura mínima de 80%.

@assertiva_geral Todas as funções seguem a tabela de decisão

bool SistemaBackup::executarBackup ( const std::string &  dispositivo)

Executa procedimento de backup.

Implementa a lógica da tabela de decisão para determinar se o backup pode ser executado baseado nas condições:

  • Existência do backup.parm
  • Disponibilidade do dispositivo
  • Estado dos arquivos
Parameters
dispositivoCaminho do dispositivo de backup (pendrive/diretório)
Returns
true se backup foi executado com sucesso
false se houve erro ou condição impossível

@assertiva_entrada dispositivo não é string vazia @assertiva_saida Retorna true apenas se backup foi realizado conforme tabela
