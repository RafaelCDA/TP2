◆ compararDatas()

int SistemaBackup::compararDatas ( const std::string &  nomeArquivo,
const std::string &  dispositivo 
) const

Compara datas entre HD e pendrive.

Implementação que usa diferença de conteúdo como proxy para versão.

  • Retorna -1: PenD < HD (pendrive desatualizado)
  • Retorna 0: PenD == HD (datas iguais)
  • Retorna 1: PenD > HD (pendrive mais atualizado)
Parâmetros
nomeArquivoNome do arquivo a comparar
dispositivoCaminho do dispositivo pendrive
Retorna
-1, 0 ou 1 conforme a comparação

@assertiva_entrada nomeArquivo e dispositivo não são strings vazias @assertiva_saida Retorna sempre -1, 0 ou 1
